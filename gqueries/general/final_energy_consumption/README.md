# Final energy consumption queries

## How to update these queries

These queries are generated by a script. **Do not edit them by hand**: changes
are lost when the set is regenerated. Change the script's input and regenerate.

## What these queries contain

Most queries give the ETM breakdown of final energy consumption (FEC): based on
`final_demand` edge groups, split by use type, sector and carrier.

A subset of these queries, plus the query in `transformation/`, replicates the
Eurostat "Final energy consumption (Europe 2020-2030)" indicator used for the EU
target. It includes energetic use only and international aviation. It excludes
the energy sector, refineries and maritime bunkers. It adds the net
transformation in blast furnaces, which is not final demand in the ETM.

The replication is not exact. For example, energy sector own use that the ETM
does not model separately (such as coke ovens and coal mines) is in industry,
so it is counted in the EU target, while Eurostat excludes it.
